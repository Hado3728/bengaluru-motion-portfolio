# Bengaluru Motion Portfolio

A small motion-led portfolio experiment inspired by the uploaded Bengaluru street, skyline and vintage-map references.

## Run it
Open `index.html` directly in a browser, or serve the folder with any static server.

Example:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## Notes
- No framework or build step required.
- The uploaded reference images are stored in `assets/`.
- Motion uses native CSS + a small vanilla JS layer.
- Replace `hello@example.com` in `index.html` with your real contact address.
- The page intentionally tells a story rather than behaving like a conventional résumé/portfolio.
